# Core Industries UI — Impeccable Design Context

> Persistent design context for the Core Industries shared design system. Referenced by all design-related skills and decisions across every CI project.

---

## Design Context

### Users
**Primary audience:** Mixed — both client-facing products and internal tools. Core Industries builds products for small business professionals (insurance agents, realtors, service providers) while also maintaining internal operations tooling for the CI team.

**Context of use:** Professionals using CI products during their workday — often on desktop, sometimes tablet. These are people who need to get things done efficiently. Internal tools are used by the CI team for ops, CRM, and workflow management. Client-facing products (CoreDocs, RealtyCore, CorePortal) need to project credibility and competence to paying customers.

**Job to be done:** Deliver polished, trustworthy interfaces that make complex workflows feel simple. Clients should feel they're using a premium product built by people who care about craft. Internal users should feel the same quality extends to their own tools.

### Brand Personality
**Three words:** Clean, modern, trustworthy.

**Voice:** Confident but not loud. Professional without being corporate. The UI speaks through precision and restraint — every element earns its place. Think "quietly excellent."

**Emotional goal:** When someone uses a Core Industries product, they should feel like they're in capable hands. The interface should project competence and attention to detail. Not flashy for flash's sake — polished because the team actually cares.

### Aesthetic Direction

**Visual tone:** Premium modern with restrained motion. Surfaces are clean and breathable. Color is used with intent — the brand orange (#FF602D) is the primary accent and should always feel deliberate, never overwhelming. Dark mode is a first-class citizen, not an afterthought.

**Design system name:** Core Industries UI

**Typography:**
- Display: Archivo (bold, geometric, modern)
- Body: DM Sans (clean, highly legible)

**Color DNA:**
- Brand orange `#FF602D` as the singular accent — used for CTAs, focus rings, active states, and emphasis
- Light mode: cool blue-gray backgrounds (`#F7F8FC`) with white surfaces
- Dark mode: warm cream text (`#F0EFE8`) on near-black (`#06060A`) — not inverted light mode, its own considered palette
- Subtle glows and gradients using brand orange at low opacity for depth and atmosphere

**Motion language:**
- Spring physics via Framer Motion (stiffness ~100, damping ~20) — bouncy but controlled
- Staggered reveals for groups of elements (0.1s delay between children)
- 3D perspective effects (flip text, card reveals) for moments of delight
- Expo and quart easing for smooth, premium transitions
- Background atmosphere: aurora gradients, flickering grids, noise texture at 1.8% opacity
- `prefers-reduced-motion` always respected

**References (what to emulate):**
- **Vercel / Linear** — Clean, fast, dark-mode-native, developer-grade polish
- **Stripe** — Premium but approachable, excellent typography and spacing
- **Raycast** — Confident dark UI, motion that feels purposeful not gratuitous
- **Apple** — That level of craft and attention to micro-details

**Anti-references (what to avoid):**
- **Generic SaaS** (HubSpot, Salesforce) — cluttered dashboards, feature-dump UIs, no visual identity
- **Overly playful** (Notion, Figma) — too whimsical, illustration-heavy, pastel-friendly
- **Corporate/legacy** (Oracle, SAP) — outdated enterprise look, dense tables, no personality
- **Template sites** (Wix, Squarespace) — generic templates that all look the same
- **AI-generic** — the "shadcn default with no customization" look that every AI-generated site has

**Theme:** Light and dark mode, both fully designed. Dark mode uses warm neutrals, not cold grays.

### Design Principles

1. **Earn every pixel.** Nothing decorative without purpose. If an element doesn't serve the user or reinforce the brand, remove it.

2. **Motion is communication.** Animations exist to show relationships, guide attention, and provide feedback — never just to look cool. Every transition should answer "what changed and why?"

3. **Dark mode is not an afterthought.** Both themes are designed independently with their own palettes, shadows, and contrast ratios. Dark mode gets warm creams and considered glows, not inverted colors.

4. **One accent, used with intent.** Brand orange is the single accent color. It marks what matters: primary actions, active states, emphasis. When everything is highlighted, nothing is.

5. **Quiet confidence over loud design.** The quality should be felt, not shouted. Subtle noise textures, considered shadows, precise spacing — the kind of craft that makes people say "this feels good" without knowing exactly why.

### Accessibility
No formal WCAG compliance target, but sensible defaults throughout:
- Focus rings on all interactive elements (2px solid brand orange, 2px offset)
- Semantic HTML and proper ARIA attributes
- `prefers-reduced-motion` disables all animations
- Sufficient contrast ratios in both light and dark modes
- Hidden scrollbars for cleaner aesthetic, but content remains scrollable

### Technical Stack
- React 18+ with TypeScript
- Tailwind CSS v4 (using `@theme` syntax for token registration)
- Framer Motion for animation
- Radix UI for accessible primitives
- class-variance-authority (CVA) for variant management
- clsx + tailwind-merge for class composition
- tsup for building
- Next.js compatible (optional peer dependency)
